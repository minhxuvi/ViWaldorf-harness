# Harness Specifications

The ViWaldorf Harness is a decoupled, everything-is-a-plugin agentic runtime designed to serve both web and native desktop environments.

3. [03 — Agent Loop](03-agent-loop.md): Autonomous task execution, streaming context, and subagent delegation.
4. [04 — Session Log](04-session-log.md): Model-visible equals logged invariant, transparent event streams.
5. [05 — Model Gateway](05-model-gateway.md): Abstraction layer supporting Meta AI / Muse and fallback local models.
6. [06 — Tools & Execution](06-tools-and-execution.md): Sandboxed file access, atomic file writes, and state mutations.
7. [07 — Synchronization Architecture](07-sync-architecture.md): Protocol for seamless bi-directional synchronization between macOS native desktop and Vercel web applications.
